# Caravan Names

Display names for the 105 caravan variations in `datapacks/Pillager_Caravans/`.

Pillager Caravans reads `caravan.<namespace>.<variation_id>` when it shows the encounter toast. Without this pack the toast shows the raw key.

All three tiers of a caravan share one name: `caravan.magic_caravans.dune_miners_tier_1`, `_tier_2` and `_tier_3` all read "Dune Miners". The mod has no tier label of its own, and the player can see the size.

Server-side only in effect, but it is a resource pack, so it has to ship to clients.

Generated alongside the datapack. Editing one without the other leaves keys unmatched.
